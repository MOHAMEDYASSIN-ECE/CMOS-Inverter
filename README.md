CMOS Inverter Design and Simulation

Project Description

This mini project focuses on designing and simulating a CMOS Inverter using Qucs-S software.

Components Used

- PMOS Transistor (BSS84)
- NMOS Transistor (BSS123)
- DC Voltage Source
- Qucs-S Simulation Software

Simulation Details

- Supply Voltage: 5V
- Input Voltage: 0V to 5V
- Simulation Type: DC Parameter Sweep

Expected Output

- When VIN = 0V, VOUT = 5V
- When VIN = 5V, VOUT ≈ 0V

Project Files

- "CMOS_Inverter.sch" – Circuit schematic
- "CMOS_Inverter_Report_Same_Format.docx" – Project report
- "CMOS_Inverter_Graph.png" – Simulation graph
- "sch.png" – Circuit screenshot
